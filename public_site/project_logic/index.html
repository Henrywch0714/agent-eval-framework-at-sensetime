Agent 评估框架三层架构

首页只展示总结构：Domain Profile 定义具体评估对象，Profile Kits 沉淀跨领域模板，Core Harness 负责稳定捕获、解析、评分和展示。 点击任一板块进入详情页，查看二次归类、逻辑说明和当前源码对应的关键片段。

评分可视化网站

Layer 01

Domain Profile

面向具体业务场景的配置层，负责声明使用哪些 kit、监听哪些接口，并补充标准答案、工具箱、日志语义覆盖和领域安全规则。

  • profile.json 组合 9 个 kit
  • 22 个标准答案 case
  • 11 个领域工具定义
  • 领域日志语义与安全覆盖

Layer 02

Profile Kits

跨领域复用的能力模板，把网页 SSE、工具轨迹、任务理解、工具 archetype、分页证据、评分权重、安全协议和 case 模板沉淀出来。

  • 网页 SSE 日志模板
  • 任务理解与多模态工具模板
  • 分页证据与视觉 grounding 模板
  • 评分、安全与 case archetype
进入 Kit 详情 →

Layer 03

Core Harness

稳定的评估执行内核，负责 profile 编译、真实或模拟日志接入、标准化、case 匹配、工具链评分、LLM Assistant 轻量辅助、报告和网页索引。

  • profile 编译
  • 日志适配与标准化
  • 证据聚合、溯源与数据流校验
  • Markdown/JSONL/Webshow 输出
